# Story 2.5: Text Lesson Authoring

Status: done

<!-- Note: Validation is optional. Run validate-create-story for quality check before dev-story. -->

## Story

As an Instructor,
I want to write a text Lesson with syntax-highlighted code blocks,
so that I can teach concepts that are better explained in writing, including code samples.

## Acceptance Criteria

1. **Given** I open a Lesson and choose the Text Lesson Type, **when** I write rich text content, including a fenced code block (e.g. SQL), **then** the code block renders with syntax highlighting, always left-to-right and monospace regardless of the page's active language direction.
2. **Given** I am editing this Lesson's text content, **when** I pause typing, **then** it autosaves as its own content-body field group, independent from outline metadata.
3. **Given** my course's content language is Arabic, **when** I write the Lesson's prose in Arabic, **then** the prose renders RTL while any embedded code block stays LTR within the same Lesson.
